# 미래과학교육원 AI·디지털 역량진단 (v2)

교원이 61문항을 탭 한 번씩으로 응답하면, 6개 역량 점수와 2026 경기도교육청미래과학교육원 연수 추천을 바로 보여 주는 웹앱입니다. 응답은 원할 때만 익명으로 구글 시트에 모입니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` · `app.js` · `style.css` | 응답자 화면 (시작 → 문항 → 결과·추천·제출) |
| `admin.html` · `admin.js` | 관리자 통계 (학교급·기간 필터, 역량 평균, 희망 연수, 낮은 문항 10개, CSV, 응답 숨기기) |
| `data.js` | 61문항과 14개 연수 정보 (공문 32건에서 추출) |
| `config.js` | 제출 서버 주소 한 줄 |
| `apps-script/Code.gs` | 구글 시트에 붙이는 저장 서버 |
| `.dev-server.js` | 내 컴퓨터에서 미리보기용 (배포에는 필요 없음) |

## 바뀐 점 (이전 GPT 버전 대비)

- 한 화면에 한 문항, **탭하면 자동으로 다음 문항**. 키보드 1~5, ←로도 응답
- 시작은 **학교급 한 번 탭**. 경력·과거 참여·관심 주제 질문을 앞에서 없앴고, 관심 주제는 결과 화면에서 눌러 추천 순서를 바꾸는 방식
- 응답 **자동 저장·이어하기** (새로고침해도 유지)
- 연수 10개 → **2026 공문 기준 14개** (기초1, 유치원, 특수, 미래형 과학실, 실행 중심 연수 추가, 2025 종료 과정 제외)
- 기수 일정으로 **"지금 신청 가능 / 다음 기수 / 2026 운영 종료"** 를 날짜에 맞춰 자동 표시
- 하이러닝 → **경기도교육청 AI교수학습플랫폼(구 하이러닝)** 으로 모두 교체
- 프리텐다드(Pretendard) 글꼴, 방사형 그래프 결과, PDF·HTML 결과 저장
- 관리자: 삭제 대신 **숨기기**(시트의 `deleted` 칸을 FALSE로 바꾸면 복구), 비밀번호는 URL이 아닌 요청 본문으로 전송

## 설치 (처음 한 번, 약 10분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script** 를 열고, `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
3. `setAdminKey()` 안의 `'여기에-관리자-비밀번호'` 를 8자 이상 비밀번호로 바꾸고, 위쪽 함수 선택에서 `setAdminKey` 를 고른 뒤 **실행**합니다. (권한 허용 창이 뜨면 허용)
4. **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자** 로 배포하고 **웹 앱 URL** 을 복사합니다.
5. `config.js` 의 `endpoint: ''` 따옴표 안에 그 URL을 붙여 넣습니다.
6. `app` 폴더를 정적 호스팅에 올립니다. (GitHub Pages, Netlify 드래그앤드롭, Vercel 등 어디든 가능)
7. `주소/admin.html` 에서 3번 비밀번호로 들어가면 통계가 보입니다.

`config.js` 를 비워 두면 **미리보기 모드**로 동작해, 제출이 그 브라우저에만 저장되고 `admin.html` 도 비밀번호 없이 그 기록만 보여 줍니다.

## 미리보기

- 결과 화면 예시: `index.html#demo`
- 내 컴퓨터에서: `node .dev-server.js` 실행 후 http://localhost:5178

## 연수 정보 고치기

`data.js` 의 `COURSES` 항목에서 이름·내용·기수(`cohorts`)를 고치면 바로 반영됩니다. 기수의 `start`·`end`·`applyEnd`(YYYY-MM-DD)가 "지금 신청 가능" 표시에 쓰입니다. `w` 는 6개 역량 연계 가중치(0~4)로 추천 계산에 쓰입니다.

## 확인이 필요한 공문 내용

- 기초2 3기: 연장 공문은 8. 5.까지, 이후 공문 일정표는 7. 28.로 표기
- 기초2 6기, 특수 5기, 유치원 2~5기: 해당 기수 공문이 폴더에 없어 다른 공문의 일정표 기준
- 전문가 과정: 모집 공문(미래교육연수부-2434)이 폴더에 없어 신청 방법은 "별도 모집 공문"으로 표기
- SW·AI 기본과정 1기 기간이 공문에 "5. 23.~5. 22."로 오기되어 세부 일정(5. 15.~5. 22.) 기준으로 넣음
- 연수별 6개 역량 가중치는 교육과정을 보고 정한 값이라, 담당 부서 검토를 권합니다
